File yang berubah:

- style-final.css (baru): lapisan tema visual (warna, fokus keyboard, sidebar, header, pengurangan animasi).
- img/projector-cinematic.webp (baru): foto proyektor dengan latar gelap.

File backend TIDAK diubah (diverifikasi dengan SHA-256 sebelum dan sesudah):
app.js, config.js, appsscript.json, sw.js, notify.js, drafts.js, sidebar.js, ux.js, manifest.json.
Code.gs (Google Apps Script) tidak ada di paket ini dan tidak disentuh.

Cara pasang: unggah isi folder ke repo seperti biasa, pastikan style-final.css ikut terunggah, lalu uji login, navigasi, dan penyimpanan laporan.
Untuk kembali ke tampilan sebelumnya, hapus baris <link> style-final.css di index.html.

Pengujian perangkat (login):
- Mobile 390x844, tablet 768x1024, desktop 1440x900: tidak ada scroll horizontal.
- Target sentuh di layar kecil dibuat minimal 44px (style-final.css).
- Navigasi mobile memakai bilah bawah (#tabs) seperti desain asli.
Catatan: tampilan dashboard dengan data asli belum diuji karena backend Apps Script tidak terhubung dari lingkungan pengujian.
